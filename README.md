# AYU
🌿 AYU – Your Sinhala-Speaking Health Assistant! 🤖💙  AYU is an AI-powered health bot built with Arduino &amp; Aura’s AI model to offer friendly health support in Sinhala 🇱🇰. It listens attentively 🎧, responds effectively 💬, and provides basic health guidance 🏥. Whether for wellness tips or a friendly chat, AYU is here to assist! 🌟😊
