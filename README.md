# 🌿 AYU – Your Sinhala-Speaking Health Assistant! 🤖💙

**AYU** is an AI-powered health assistant bot developed by **Team AURA**. Built with **Arduino & AURA’s AI model**, AYU provides **friendly** and **intelligent** health support in **Sinhala** 🇱🇰. It listens attentively 🎧, responds effectively 💬, and offers basic health guidance 🏥 to enhance accessibility and wellness.

## 🚀 Features
- 🗣️ **Converses in Sinhala** for a natural and comfortable experience
- 🎧 **Attentive listening** and meaningful responses
- 🏥 **Basic health guidance** for instant support
- 📊 **Future-ready** with potential for smart health tracking
- ⚡ **User-friendly and interactive** design

## 🛠️ Technologies Used
### **Phase 1: Web-Based AI**
- **PHP, CSS, JavaScript** for frontend & backend development 🖥️
- **Python** for AI model integration and backend processing 🐥
- **JSON** for data interchange between frontend and backend 📝🔄
- Vector **Embedding** for improved **NLP** capabilities and semantic search 📊🧠
- **SingleStore** for database management (instead of MySQL) 💾
- **VS Code** for development environment 🧑‍💻
- **Postman** for API testing 📡
- **XAMPP** for local server setup ⚙️
- **GitHub** for version control and collaboration 🔧🌐
- **ChatGPT API, Gemini API, and Eleven Labs API** for AI-powered responses 🤖🌐📢

### **Phase 2: Hardware Integration**
- **Arduino** for hardware integration
- **C/C++** for microcontroller programming
- **Natural Language Processing (NLP)** for smooth conversations
